# Minecraft

A collection of my Minecraft build designs, ideas, and plans.

## Structure

- `designs/` — individual build write-ups, grouped into subfolders by version/edition (e.g. `designs/java1.21/`), one markdown file per design

## Design template

Each file in `designs/<version>/` follows roughly this format:

```markdown
# Build Name

**Type:** (e.g. house, farm, redstone contraption, base)
**Version/Edition:** (e.g. Java 1.21)

## Overview
Short description of the build.

## Materials
- List of blocks/items needed

## Notes
Design notes, dimensions, screenshots, links, etc.
```
